## 📖 Overview

Pokédex Pro is a production-quality Pokémon application built with the latest React ecosystem.

The goal of this project is to demonstrate modern frontend engineering practices including:

- Clean Architecture
- Type-safe development
- Server-state management
- Component-driven UI
- Accessibility
- Testing
- Professional Git workflow
- Continuous Integration

Rather than being just another Pokédex, this project serves as a portfolio-quality example of building scalable React applications.

# 🚀 Getting Started

## Clone

```bash
git clone git@github.com:mokone-september/pokedex-pro.git
```

```bash
cd pokedex-pro
```

---

## Install

```bash
pnpm install
```

---

## Development

```bash
pnpm dev
```

Open

```
http://localhost:3000
```

---

## Build

```bash
pnpm build
```

---

## Run Production

```bash
pnpm start
```

---

# 🧪 Testing

Run all tests

# 📦 Git Workflow

This project follows a feature branch workflow.

Example:

```text
main
 │
 ├── feature/pokeapi-integration
 │
 ├── feature/pokemon-search
 │
 ├── feature/pokemon-details
 │
 └── feature/favorites
```

Every feature is developed in its own branch and merged through a Pull Request.
